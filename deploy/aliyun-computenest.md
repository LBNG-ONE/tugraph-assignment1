# 部署方式一：阿里云计算巢免费试用（本实验采用）

> 依据课程 PPT「启动 TuGraph - 方法 1：在阿里云计算巢免费试用」整理。

## 1. 开通实例

1. 打开 [阿里云登录页](https://account.aliyun.com/login/login.htm) 登录账号。
2. 进入 **控制台** → 左上角「最近访问」→ **计算巢**。
3. 左侧菜单：**服务实例** → **试用服务**。
4. 找到 **TuGraph 社区版 / TuGraph 服务** 试用服务 → 点击「创建服务实例」。
5. 填写实例参数（地域、规格、可用区、密码），提交。
6. 等待部署状态变为 **已部署 / Running**（通常需要 1~5 分钟）。

## 2. 获取访问信息

在 **服务实例 → 详情** 页可以查到：

| 项 | 说明 |
|---|---|
| **Browser 地址** | Web 管理界面，形如 `http://<公网IP>:7070` |
| **password** | admin 账号的登录密码（默认 `73@TuGraph`，创建时也可自定义） |
| **Bolt 地址** | Bolt 协议地址，形如 `bolt://<公网IP>:7687` |

> 若查不到端口，进入 **资源 → 远程连接**，或用命令行查看容器端口映射。

## 3. 放通端口（关键，否则浏览器打不开）

在 **资源 → 安全组** 中添加入方向规则：

| 端口 | 用途 | 是否必须 |
|---|---|---|
| 7070 | Web 管理界面 / RESTful API | ✅ 必须 |
| 7687 | Bolt 协议（客户端驱动连接） | 需要写代码时开 |
| 9090 | 监控 / gRPC | 可选 |

## 4. 登录系统

浏览器访问 `http://<公网IP>:7070`：

- 用户名：`admin`
- 密码：创建实例时设置的密码（未修改则为默认 `73@TuGraph`）
- 子图：`default`

登录成功即可进入 TuGraph Web 可视化控制台。

## 5. 试用期注意事项

- 试用期 **7 天**，到期后 **数据不保留**。
- 到期后可再次申请试用，需要 **申请配额 → 等待审核（约 24 小时）→ 重新配置参数**。
- 因此请务必在试用期内完成实验与截图，并把 CSV / Cypher 脚本留存到本仓库。
